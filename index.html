About This Project

Animal Species Recognition is a deep learning project that classifies animal images into five categories using a MobileNetV2-based image classification model.

Project Objectives

  • Recognize animals from uploaded images.
  • Apply deep learning to image classification.
  • Display the predicted animal, category, and confidence score.
  • Provide a web interface for trying the trained model.

Supported Animals

  • Cat
  • Dog
  • Elephant
  • Horse
  • Lion

Dataset Information

The dataset contains images organized into five animal classes for model training and validation.

13,496 Training images
1,500 Validation images
300 Validation images per class
224 × 224 Model input image size
Download Animal Dataset (ZIP)

The dataset is hosted on Google Drive. Access depends on the sharing permissions of the file.

Model Information

Architecture: MobileNetV2-based CNN classifier

Framework: TensorFlow / Keras

Input size: 224 × 224 pixels

Number of classes: 5

Training epochs: 5

Model formats: Keras (.keras) and TensorFlow Lite (.tflite)

96.80% Validation accuracy

The reported accuracy is measured on the validation dataset. It does not guarantee the same accuracy on every new image. Confidence scores are model outputs and may not always represent true prediction reliability.
